# Repository Skills

These are repo-local Cursor skills for the stack used in this project.

## Available skills

- `tailwind` - Styling/layout/typography conventions
- `remix` - Route and app-shell conventions
- `react` - Component patterns and safety checks
- `typescript` - Type-safe implementation guardrails
- `vite` - Build/dev config guidance
- `headlessui` - Accessible UI primitives and icon usage
- `biome` - Lint/format rules and validation workflow
- `remix-content` - CV copy, tone, and data file conventions

Use these as defaults when editing related areas to keep changes consistent and minimal.
